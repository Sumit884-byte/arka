================================================================================
WHAT ARKA IS
================================================================================

  Open-source AI terminal agent (MIT). Say what you want in plain English.
  Arka routes the request to a local skill on this machine, or to an LLM
  when a skill does not apply — then can speak the answer back.

  Tagline (landing): "Your terminal, upgraded."
  Package: arka-agent. No Docker, no hosted account required.

  Official pages
  - Site     https://arka-agent-liart.vercel.app/
  - Docs     https://arka-agent.mintlify.site

================================================================================
HOW IT WORKS (do not invent a different pipeline)
================================================================================

  Ask (plain English)
    → Route (120+ symbolic rules, token-free when they match)
      → Skills (70+ local: media, web, PDF RAG, Google Workspace, charts,
         stocks, YouTube, voice, repo tools, system …)
      → or LLM (24-provider failover: Gemini, Groq, OpenAI, Anthropic,
         Ollama, vLLM, OpenRouter, …)
    → Output (result; optional voice / TTS)

  Offline-first: a symbolic match spends zero LLM tokens.
  Security: prompt-injection checks, risky-action prompts, hard blocks
  on destructive shell. Review outputs before applying changes.
  MCP: Cursor, Claude Desktop, and other MCP clients via arka_route /
  arka_ask. Plugins: third-party skill.json, no fork required.

  Install
    pipx install "arka-agent[chat]"
    arka setup && arka doctor
    arka ask "what is Rust?"

  Landing suggestions that are real
    - Check setup     → arka doctor
    - Repo health     → repo_health
    - Capabilities    → this file / arka capabilities
    - Weather         → weather / hyperlocal_weather
    - High CPU        → processes (live ps, never web search)

ASK OUTPUT CONTRACTS (SEMANTIC VERIFY)
================================================================================

  CI on every push: pytest tests/test_llm_txt_semantic_verify.py
  Offline bag-of-words cosine vs must_mean/good. Optional AI judge: ARKA_SEMANTIC_AI=1

  Live ask / web_answer rules
  - Country news: "what happened in {country} today" searches "{Country} {date} breaking news"
    not a newspaper (usa today ≠ USA Today unless usatoday.com / newspaper).
  - Pick 4 leads and write a short briefing; drop polls, newsletters, extra world briefs.
  - Brief from article titles; never refuse for missing snippets.
  - Drop date-index pages, section fronts, live YouTube, "News Headlines" titles.
  - Reject meta filler: "major developments unfolding", "coverage is available".
  - Flagship events (GTC, WWDC, I/O, Build, …): official YouTube transcript + search,
    recap length scales with keynote runtime; skip teaser descriptions.
  - Stream tokens on a TTY (ARKA_STREAM=0 to buffer). Pipes/pytest stay buffered.
  - Do not open event.com for "launch event". Apple/NVIDIA recaps are not stock predict.
  - Local machine asks are skills, never web_answer: "show high CPU processes"
    or "show cpu stats" → processes (live ps / load). Specs → system_info. Disk → disk_usage.
  - Default routing is symbolic_only. Do not [AI routing] local sysadmin phrases.

### case: what-can-you-do
question: what can you do
must_mean: Arka is a local terminal agent with 70+ skills, offline routing, and LLM failover
must_not: Caterpillar; only a chatbot; hosted SaaS
good: Arka is an open-source terminal agent. Say it in English and it routes to a local skill or an LLM. Try doctor, repo health, weather, or show high CPU processes.
bad: I am only a chatbot. I cannot run local skills or list processes on your machine.

### case: usa-today
question: what happened in usa today
must_mean: specific United States events such as a vote, storm, ruling, or bill with article links
must_not: unfolding; cannot fulfill; News Headlines; news broadcast; coverage is available
good: The Senate passed a stopgap funding bill after overnight talks, keeping federal agencies open.
bad: Today in the United States, major national developments and breaking news stories are unfolding across the country.

### case: news-refusal
question: what happened in usa today

must_not: cannot fulfill; do not contain any text; no content snippets
good: Here is what news outlets are reporting in the United States today: Senate passes funding bill.
bad: I cannot fulfill this request. The provided search results do not contain any text or content snippets to summarize.
