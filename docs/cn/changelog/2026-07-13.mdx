## 新功能

- **[Arka 议会](/cn/guides/council)。** 多人格审议 —— 苏格拉底、Elon 和 Feynman 各自独立回答同一个问题，然后 Arka 综合出共识、分歧和结论。
- **[测验练习](/cn/guides/quiz-practice)。** 在任何主题上进行无限次测验，具备按主题的记忆，因此问题永不重复。
- **[时区转换](/cn/guides/timezone-convert)。** `arka convert 9am PDT to IST` 以及自然语言的日期/时间转换；能与货币 `convert` 消歧。
- **[打开 URL](/cn/guides/open-url)。** `arka open youtube` 会在默认浏览器中打开站点（与 `play_youtube` 不同）。
- **[有趣的事实](/cn/guides/interesting-fact)。** 无需联网搜索的轻量小知识 —— `tell me something interesting`。
- **[自我改进循环](/cn/guides/self-improve)。** `arka self improve` 分析代码库，并可通过 `--apply` 选项应用修复。
- **[操作模式](/cn/guides/operation-modes)。** 使用 `arka mode debug` 查看路由 trace；默认的 `agent` 模式保持输出简洁。
- **[compose 幻灯片](/cn/guides/compose-slides)。** 高管/路演/学术风格预设、行动式标题、经过校验的 pptx 导出以及 markdown 回退。
- **前端视觉循环。** Arka 现在可以检视自己前端的截图、评估精细度，并重试构建命令最多 N 轮。
- **领域智能体。** 天文、冶金、事实核查、科学流程、Harvard ARK 生物医学 KG、代码库上下文索引。
- **提供方 CLI。** `arka provider list/set/show/models` 支持 OpenRouter 实时自动检测。
- **通过 MCP 的 CSV/TSV 表格预览。** 为已连接的 MCP 客户端提供干净的结构化预览。

## 改进

- 除非显式配置，否则 LLM 回退跳过 vLLM；除非在调试模式下否则隐藏 trace。
- 当存在 key 时，OpenRouter credit 错误会回退到 Gemini/Groq。
- 自我改进和目标智能体使用干净的面向用户的输出（正常模式下不再打印 llm.txt 转储）。
- CI 已修复：`ai_only` 模式下的剪贴板路由、`src/` 和 `tests/` 全面通过 ruff lint。

## 文档

- 为上述所有功能新增了指南页；孤立的指南（bookmarks、clipboard-history、docker-status、repo-health）已加入导航。
