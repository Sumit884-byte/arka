---
title: "语义截止日期提醒"
description: "根据自然语言的截止日期请求创建本地提醒。"
icon: "bell"
---

Arka 能理解如下请求：

```text
alert me when OpenAI Build Week deadline arrives
```

由于活动日期可能变更，Arka 不会猜测截止日期。请提供经过验证的日期或来源：

```bash
arka semantic-alert "OpenAI Build Week deadline" \
  --at 2026-08-01T17:00:00 \
  --source https://example.com/official-deadline
```

提醒存储在本地，并使用 Arka 的提醒守护进程发送通知。

对于未来的机会，Arka 能识别诸如“alert me whenever a new OpenAI hackathon or program comes.”之类的请求。这会成为一个周期性的项目监控，但在激活之前需要提供官方的列表/搜索来源和检查间隔；Arka 不会编造活动日期，也不会静默轮询网络。
