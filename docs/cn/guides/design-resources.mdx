Arka 使用 [Design Resources for Developers](https://github.com/bradtraversy/design-resources-for-developers)
作为设计工作流的默认发现目录。

```bash
arka design-resources
arka design-resources prompt
```

该目录据称采用 MIT 许可证，但在用于生产环境之前，你必须单独核查每个链接的字体、图标、模板或素材。
