启用后可将追踪、指标和日志导出到 [SigNoz](https://signoz.io)。**默认开启**，本地 OTLP 端点为 `http://127.0.0.1:4318`。

## 快速开始

```bash
arka signoz status
arka signoz setup -y
arka signoz demo
arka ai trace-status
arka observability doctor
```

## 配置

```env
# 默认开启 — 仅在需要时覆盖
SIGNOZ_ENDPOINT=http://localhost:4318
SIGNOZ_UI_URL=http://localhost:8080
OTEL_SERVICE_NAME=arka
# OTEL_SDK_DISABLED=true          # 关闭所有 OTLP 导出
# OTEL_TRACES_ENABLED=0           # 关闭追踪（指标/日志跟随追踪）
# SIGNOZ_API_KEY=               # 用于告警 / MCP
```

## 追踪内容

- LLM 提供商调用（模型、延迟、令牌、故障转移事件）
- 技能调度和路由决策
- MCP 客户端调用
- Supermemory 操作

## SigNoz MCP + Cursor

```bash
arka signoz mcp tools
arka signoz cursor-setup
```

捆绑的 SigNoz 资产（仪表板、告警、演示）位于仓库的 `signoz/` 中。

<Note>
  OTLP 导出默认指向 `http://127.0.0.1:4318`。设置 `OTEL_SDK_DISABLED=true` 或 `OTEL_TRACES_ENABLED=0` 可关闭。
</Note>
