当你希望 Arka 在截止时间前收集多条提示词，然后将它们作为一个连贯的实现请求发送给编码代理时，请使用 `arka batch`。

```bash
arka batch start --until "6pm"
arka batch add "fix routing drift"
arka batch add "add regression tests"
arka batch list
arka batch run
```

支持自然语言路由：

```bash
arka collect all prompts until 6pm
arka batch add improve the coding TUI
arka run batch
```

`arka batch run` 会通过 `agent_code` 立即执行。`arka batch due` 仅在批处理截止时间到达时才会执行。使用 `--print` 可查看合并后的模型提示词而不实际运行：

```bash
arka batch run --print
arka batch due --print
```

默认情况下，成功运行后会清空批处理。如果希望保留已收集的提示词，请传入 `--keep`。
