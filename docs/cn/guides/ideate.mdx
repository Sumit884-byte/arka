使用 Arka Ideate 在动手构建之前探索开源生态的势头：

```bash
arka ideate "open-source AI developer tools"
arka ideate "trending frontend infrastructure" --deep
```

该工作流会让 Arka 查看当前的 GitHub / package / 讨论信号、许可证、维护情况、未解决 issue 以及集成阻力，然后识别一个未被满足的问题并提出具体的改进建议。请使用实时网络或 MCP 研究作为证据；仅凭流行度并不构成产品验证。
