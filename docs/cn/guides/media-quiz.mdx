围绕图片、视频、音频文件或 PDF 生成一个测验网站：

```bash
arka media-quiz lesson.mp4
arka media-quiz lecture.png --title "Lecture review" --output public/quiz.html
```

生成的页面会嵌入媒体，并提供带答题提交和评分钩子的响应式测验表单。用于正式测评时请添加经过校验的题目和答案；Arka 不会为它无法解析的媒体凭空捏造事实性答案。「make a quiz website from lesson.mp4」这类自然语言也支持。
