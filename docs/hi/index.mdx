Arka एक **क्रॉस-प्लेटफ़ॉर्म AI टर्मिनल एजेंट** है। आप सादी अंग्रेज़ी या हिंदी में बताइए कि आपको क्या चाहिए। Arka आपके अनुरोध को सही स्थानीय स्किल पर रूट करता है, उसे चलाता है, और आप चाहें तो जवाब बोलकर सुनाता है।

कमांड स्थानीय रूप से चलती हैं। LLM कॉल **24 प्रोवाइडर्स** में एक **फ़ॉलबैक ऑर्केस्ट्रेटर** के ज़रिए जाती हैं। रोज़ाना उपयोग के लिए आपको Docker की ज़रूरत नहीं है।

## त्वरित इंस्टॉल

```bash
pipx install "arka-agent[chat]"
arka setup
arka doctor
arka ask "Rust क्या है?"
```

## दैनिक पढ़ाई — एक कमांड

```bash
arka health_reading today --minutes 40
arka daily_reading init "भारतीय संविधान के मूल सिद्धांत"
arka daily_reading today
```
