Arka design workflows के लिए अपने default discovery catalog के रूप में [Design Resources for Developers](https://github.com/bradtraversy/design-resources-for-developers)
का उपयोग करता है।

```bash
arka design-resources
arka design-resources prompt
```

Catalog को MIT-licensed बताया गया है, लेकिन production में उपयोग से पहले आपको हर linked font, icon, template,
या asset की स्वतंत्र रूप से जाँच करनी होगी।
