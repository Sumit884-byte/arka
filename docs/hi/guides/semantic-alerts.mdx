---
title: "Semantic deadline alerts"
description: "Natural-language deadline requests से local alerts बनाएँ।"
icon: "bell"
---

Arka इस तरह की requests समझता है:

```text
alert me when OpenAI Build Week deadline arrives
```

चूँकि event की तारीखें बदलती रहती हैं, Arka किसी deadline का अनुमान नहीं लगाएगा। एक verified
तारीख या source दें:

```bash
arka semantic-alert "OpenAI Build Week deadline" \
  --at 2026-08-01T17:00:00 \
  --source https://example.com/official-deadline
```

Alert locally store होता है और notification के लिए Arka के reminder daemon का उपयोग करता है।

भविष्य के अवसरों के लिए, Arka “alert me whenever
a new OpenAI hackathon or program comes” जैसी requests को पहचानता है। यह एक recurring program
watch बन जाता है, लेकिन activation से पहले इसे एक official listing/search source और एक interval
की आवश्यकता होती है; Arka event की तारीखें नहीं गढ़ेगा और न ही चुपचाप web को poll करेगा।
