जब आप चाहते हैं कि Arka किसी deadline तक कई prompts इकट्ठा करे और फिर उन्हें एक सुसंगत implementation request के रूप में coding agent को भेजे, तब `arka batch` का उपयोग करें।

```bash
arka batch start --until "6pm"
arka batch add "fix routing drift"
arka batch add "add regression tests"
arka batch list
arka batch run
```

Natural language routes समर्थित हैं:

```bash
arka collect all prompts until 6pm
arka batch add improve the coding TUI
arka run batch
```

`arka batch run` तुरंत `agent_code` के माध्यम से execute होता है। `arka batch due` केवल तभी execute होता है जब batch की deadline आ चुकी हो। Combined model prompt को चलाए बिना देखने के लिए `--print` का उपयोग करें:

```bash
arka batch run --print
arka batch due --print
```

Default रूप से, एक सफल run batch को साफ़ कर देता है। यदि आप इकट्ठा किए गए prompts को सुरक्षित रखना चाहते हैं, तो `--keep` pass करें।
