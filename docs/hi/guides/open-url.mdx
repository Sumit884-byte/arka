Terminal छोड़े बिना अपने default system browser में sites खोलें।

## Quick start

```bash
arka open youtube
arka open github.com
arka open https://news.ycombinator.com
arka browse google
open google in browser
```

## Site aliases

सामान्य नाम स्वचालित रूप से URLs पर map होते हैं:

| Name | खोलता है |
| --- | --- |
| `youtube` | https://youtube.com |
| `google` | https://google.com |
| `github` | https://github.com |
| `reddit` | https://reddit.com |
| `wikipedia` | https://wikipedia.org |
| `hackernews` / `hn` | https://news.ycombinator.com |

पूर्ण `https://` URLs और `domain.tld` patterns जैसे हैं वैसे काम करते हैं।

Arka आपके द्वारा दिए गए path और query को रखता है। तो `open https://example.com/docs?a=1`
नया आविष्कार करने के बजाय ठीक उसी URL को खोलता है।

## Browser app launchers

Browser के bare नाम matching `.com` site खोलने के बजाय installed desktop browser app को launch करते हैं:

| Name | Launch करता है |
| --- | --- |
| `brave` | Brave Browser |
| `chrome` / `googlechrome` | Google Chrome |
| `chromium` | Chromium |
| `firefox` | Firefox |
| `safari` | Safari (macOS) |
| `edge` / `microsoftedge` | Microsoft Edge |
| `arc` | Arc |
| `vivaldi` | Vivaldi |
| `opera` | Opera |

```bash
arka open brave
arka open firefox
arka launch chrome
```

Alias केवल bare token पर trigger होता है। इसके बजाय matching website खोलने के लिए URL जैसा target दें:

```bash
arka open brave.com
arka open https://firefox.com
```

Arka macOS पर `open -a "<App>"`, Windows पर `start`, और Linux पर `PATH` में पहले matching binary को call करता है (उदाहरण के लिए `brave-browser`, `google-chrome`, `microsoft-edge`)। यदि app installed नहीं है, तो Arka `Could not launch '<App>'` print करता है और non-zero status से exit करता है।

Natural language उदाहरण:

```bash
arka open this exact url https://example.com/docs?a=1
arka repair broken links in this file
```

## बनाम play_youtube

| Phrase | Skill |
| --- | --- |
| `arka open youtube` | Browser में youtube.com खोलता है |
| `arka play lofi on youtube` | YouTube playback skill |

Arka **open** (browser) को **play** / **watch** (media) से अलग करता है।

## Commands

| Command | विवरण |
| --- | --- |
| `arka open <site-or-url>` | Default browser में खोलें |
| `arka browse <site-or-url>` | Alias |
| `open_url <target>` | Direct skill (fish) |
