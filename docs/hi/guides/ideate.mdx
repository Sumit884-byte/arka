बनाने से पहले open-source की गति का पता लगाने के लिए Arka Ideate का उपयोग करें:

```bash
arka ideate "open-source AI developer tools"
arka ideate "trending frontend infrastructure" --deep
```

यह workflow Arka से मौजूदा GitHub/package/discussion signals, licenses, maintenance, open issues, और integration friction की जाँच करने के लिए कहता है, फिर एक underserved समस्या की पहचान करता है और एक concrete सुधार सुझाता है। साक्ष्य के लिए live web या MCP research का उपयोग करें; अकेले popularity product validation नहीं है।
