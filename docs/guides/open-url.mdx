Open sites in your default system browser without leaving the terminal.

## Quick start

```bash
arka open youtube
arka open github.com
arka open https://news.ycombinator.com
arka browse google
open google in browser
```

## Site aliases

Common names map to URLs automatically:

| Name | Opens |
| --- | --- |
| `youtube` | https://youtube.com |
| `google` | https://google.com |
| `github` | https://github.com |
| `reddit` | https://reddit.com |
| `wikipedia` | https://wikipedia.org |
| `hackernews` / `hn` | https://news.ycombinator.com |

Full `https://` URLs and `domain.tld` patterns work as-is.

Arka keeps the path and query you provide. So `open https://example.com/docs?a=1` opens that exact URL instead of inventing a new one.

## Browser app launchers

Bare browser names launch the installed desktop browser app instead of opening the matching `.com` site:

| Name | Launches |
| --- | --- |
| `brave` | Brave Browser |
| `chrome` / `googlechrome` | Google Chrome |
| `chromium` | Chromium |
| `firefox` | Firefox |
| `safari` | Safari (macOS) |
| `edge` / `microsoftedge` | Microsoft Edge |
| `arc` | Arc |
| `vivaldi` | Vivaldi |
| `opera` | Opera |

```bash
arka open brave
arka open firefox
arka launch chrome
```

The alias triggers on the bare token only. To open the matching website instead, pass a URL-like target:

```bash
arka open brave.com
arka open https://firefox.com
```

Arka calls `open -a "<App>"` on macOS, `start` on Windows, and the first matching binary on `PATH` on Linux (for example `brave-browser`, `google-chrome`, `microsoft-edge`). If the app is not installed, Arka prints `Could not launch '<App>'` and exits non-zero.

Natural language examples:

```bash
arka open this exact url https://example.com/docs?a=1
arka repair broken links in this file
```

## vs play_youtube

| Phrase | Skill |
| --- | --- |
| `arka open youtube` | Opens youtube.com in browser |
| `arka play lofi on youtube` | YouTube playback skill |

Arka disambiguates **open** (browser) from **play** / **watch** (media).

## Commands

| Command | Description |
| --- | --- |
| `arka open <site-or-url>` | Open in default browser |
| `arka browse <site-or-url>` | Alias |
| `open_url <target>` | Direct skill (fish) |
