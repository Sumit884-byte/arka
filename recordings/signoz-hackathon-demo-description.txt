See inside your AI agents — not just that something failed, but which step broke.

Arka is an open-source terminal agent. SigNoz is OpenTelemetry-native observability. Together they trace the full agent lifecycle: routing → LLM attempts → RAG retrieval → tool calls → failover — in one waterfall.

Submission for Agents of SigNoz (Track 01 — AI & Agent Observability).

HOW WE USE SIGNOZ
━━━━━━━━━━━━━━━━━━━━

1. DEPLOY — SigNoz runs locally via Foundry (casting.yaml at repo root). One command brings up the SigNoz UI (:8080), OTLP ingester (:4318), and MCP server (:8000):
   arka signoz setup -y

2. INSTRUMENT — Arka exports OpenTelemetry from src/arka/telemetry/ over OTLP HTTP. Every agent step becomes a span:
   • arka.request → arka.route → arka.agent.goal → arka.llm.attempt → arka.tool.shell
   • Metrics: arka.routing.decisions, arka.skill.duration, arka.llm.tokens
   • Logs: structured agent events with trace_id / span_id correlation

3. EMIT TRACES — Demo scenarios tag spans with arka.demo.scenario so you can filter in SigNoz without guessing:
   arka signoz demo-scenarios --synthetic
   (inference latency, RAG cascade, router split, E2E pillars, exception stack traces)

4. DEBUG IN SIGNOZ UI — Stock views, no custom dashboard required for the demo:
   • Traces Explorer — filter service.name = 'arka' → full agent waterfall
   • Services — P99 latency, error rate, ops/sec for the arka service
   • Logs Explorer — LLM failover, 429 recovery, shell events on the same trace IDs

5. VERIFY — arka signoz status confirms Docker, foundryctl, OTLP pipelines, and built-in verify queries.

6. OPTIONAL — Bundled dashboards (arka signoz dashboard install), alerts (arka signoz alert-create), and SigNoz MCP for Cursor (query traces from the IDE).

REPRODUCE IN 10 MINUTES
━━━━━━━━━━━━━━━━━━━━

git clone https://github.com/Sumit884-byte/arka.git
cd arka
pip install -e ".[chat,observability]"
arka signoz setup -y

# ~/.config/arka/.env
OTEL_TRACES_ENABLED=1
OTEL_METRICS_ENABLED=1
OTEL_LOGS_ENABLED=1
SIGNOZ_ENDPOINT=http://localhost:4318

arka signoz demo-scenarios --synthetic
# Open http://localhost:8080 → Traces Explorer → service.name = 'arka'

Or install without cloning:
uv tool install "arka-agent[chat,observability]"
