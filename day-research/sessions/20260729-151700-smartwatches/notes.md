## MIP Display Impact on Battery Life

Building on battery findings from prior research, MIP displays used by Garmin and COROS have been found to be power-efficient, drawing power only when pixels change. This is because every pixel has its own small memory cell and the pixel is only refreshed if a value changes. As a result, MIP displays are much more efficient on battery life, especially when compared to AMOLED displays. In fact, MIP watches like the FR955 don't need to turn the display off, unlike AMOLED watches like the FR965, as the screen only dims but doesn't turn off after a set timeout value.

The power efficiency of MIP displays is particularly noticeable in bright outdoor conditions, where they can remain visible without consuming significant battery power. In contrast, LCD and AMOLED displays need to shine brighter than the sun, resulting in higher battery consumption. However, it's worth noting that MIP displays may not be as bright as AMOLED displays, which can be a drawback in certain situations.
