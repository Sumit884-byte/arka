Features

Local-first power, cloud when you need it

Deterministic offline routing handles most requests with zero LLM tokens. Security gates, voice, and MCP integrations ship on by default.

Offline-first routing

120+ symbolic rules map natural language to skills before any model is called — fast and token-free.

70+ local skills

Media, web, PDF RAG, Google Workspace, charts, stocks, YouTube, voice, and more — all on your machine.

24-provider failover

Gemini, Groq, OpenAI, Anthropic, Ollama, vLLM, OpenRouter, and others — automatic fallback chain.

Security by default

Prompt-injection checks, risky-action prompts, and hard blocks on destructive shell patterns.

Voice & MCP

Wake-word listener with TTS replies. Connect to Cursor, Claude Desktop, and any MCP server.

Extensible plugins

Add third-party skills via skill.json triggers — no fork required.

How it works

From install to first answer in minutes

No Docker, no hosted account, no build step. Arka runs entirely on your system.

1

Install

Grab the published package from PyPI with pipx or uv — no git clone needed.

pipx install "arka-agent[chat]"
2

Configure

Add at least one API key or point to local Ollama. Run the health check.

arka setup && arka doctor
3

Ask

Type or speak in plain English. Arka routes, runs, and returns the result.

arka ask "what is Rust?"
Get started

Ready to try Arka?
